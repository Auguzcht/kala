## Context
A local closeout explains why student rewards should not be extended mechanically to teachers and admins.

## Decision
Preserve the accepted product rationale: students receive effort/spacing feedback through XP and streaks; instructors need cohort movement and evidence gaps; admins need coverage and adoption. This record adds no new dashboard feature.

## Consequences
Full instructor/admin requirements and acceptance remain WI-08/WI-10. Historic XP arithmetic in the source is superseded by current code and must not be copied into a new requirement.

## Alternatives considered
Teacher XP/badges would reward tool usage instead of the cohort changes teachers can act on.
